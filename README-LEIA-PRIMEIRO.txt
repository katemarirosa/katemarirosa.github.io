# Site profissional — Katemari Rosa (versão 1.0)

## Publicação no GitHub Pages — instruções para esta conta

O nome de usuário informado é `katemarirosa`. O repositório do site deve se chamar exatamente:

`katemarirosa.github.io`

1. Entre em https://github.com com sua conta.
2. No canto superior direito, clique no sinal **+** e escolha **New repository**.
3. Em **Repository name**, escreva `katemarirosa.github.io`.
4. Selecione **Public** e clique em **Create repository**.
5. Nesta pasta ZIP, extraia os arquivos para uma pasta do computador.
6. Na página do novo repositório, clique em **Add file → Upload files**.
7. Arraste para a área de upload os arquivos `index.html`, `styles.css`, `script.js` e a pasta `assets` (não envie o arquivo ZIP).
8. Clique em **Commit changes**.
9. No repositório, abra **Settings → Pages**.
10. Em **Build and deployment**, escolha **Deploy from a branch**.
11. Selecione a branch `main` e a pasta `/ (root)`; clique em **Save**.
12. Aguarde alguns minutos e acesse: https://katemarirosa.github.io
